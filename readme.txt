NXP Middleware EdgeFast Open Bluetooth

Overview
EdgeFast Open Bluetooth is NXP's Bluetooth middleware for MCUXpresso SDK.
It is based on the Zephyr Bluetooth Host stack and ported to run on FreeRTOS, providing a Zephyr-like Bluetooth API for MCUXpresso SDK applications.

This repository delivers the EdgeFast Open middleware component that is included as part of the MCUXpresso SDK overall delivery.
To build and run EdgeFast Open examples, please use the full MCUXpresso SDK package.
