# Bluetooth features

-   Bluetooth 5.3 compliant
-   Protocol support
    -   L2CAP, GAP, GATT, RFCOMM, SDP, SM, and SPP
-   Classic profile
    -   A2DP, HFP, AVRCP, AVRCP Cover Art, GOEP, BIP, MAP, PBAP
-   LE profile
    -   HTP, PXP, IPSP, HPS
-   LE audio
-   Digital Audio Interface including PCM interface for HFP
