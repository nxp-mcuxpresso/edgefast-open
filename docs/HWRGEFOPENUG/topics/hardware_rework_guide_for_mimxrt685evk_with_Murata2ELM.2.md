# Hardware Rework Guide for Low Power Feature on MIMXRT685-EVK and Murata 2EL M.2 Module

This section is a brief hardware rework guidance of the EdgeFast Open for low power feature on the NXP i.MX MIMXRT685-EVK board and the Murata's 2EL - Indirectly connect using uSD-M.2 Adapter to Embedded Artists' Rev-A1 \(2EL\) M.2 modules.

The hardware rework has three parts:

-   HCI UART rework
-   Host wake-up controller pin rework \(H2C\)
-   Controller wake-up host pin rework \(C2H\)
